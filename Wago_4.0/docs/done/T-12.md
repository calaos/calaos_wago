# T-12 — rien ne permet d'observer le rack, les offsets ni la 647 depuis l'extérieur

**Statut** : ✅ clos le 2026-09-14 *(partiel)* · **Type** : feature · **Commit** : `6461362`

> Partiel sur deux points. La verification du paragraphe 2.2 - `WAGO_MODULE` est-il parse par nombre de champs dans `calaos_base` ? - n'a pas pu etre faite, le depot n'est pas sur ce poste ; l'extension en fin de trame est livree quand meme, avec le repli `WAGO_GET_MODULE_DESC` en reserve. Et les six acceptations restent a jouer au banc, [BENCH-647.md](../BENCH-647.md). Relecture `codesys-review` : CONFORME AVEC RESERVES ; ses reserves ont donne le `NA` sur tous les champs hors borne, le `NA` sur `ERROR`, et la reecriture de E2.

---

## 1. Les essais E3/E4 ne sont pas exécutables en l'état

Le protocole de banc ([BENCH-647.md](../BENCH-647.md)) doit lire, pour chaque rack, `start_addr_in`,
`start_addr_out`, `ScanError`, `Config.AddrDali647In/Out`, le dernier `bFeedback` du maître 647, et
l'image de sortie. Aucun de ces éléments ne sort de l'automate :

- `WAGO_GET_INFO` (`UDPSERVER.EXP:163-179`) ne remonte que sept comptes ;
- `WAGO_GET_INFO_MODULE <n>` (`:181-194`) remonte `moduleType`, `physicalPos`, `sizePAE`, `sizePAA`
  — ni `posPAE`/`posPAA`, ni `channels`, ni `altFormat`, et `p1` n'est pas borné (`info[p1]` avec
  `p1 > 63` lit hors tableau) ;
- `bFeedback` est écrit dans `daliFeedback` (`DALIPRG647.EXP:37`) et **jamais relu** ;
- `READ_OUTPUT_WORD` existe dans `mod_com` et n'est instancié nulle part.

⛔ Instrumenter par une variable localisée est interdit : elle recréerait exactement la condition
que l'on cherche à mesurer (§8 du dossier).

## 2. Ce qui est demandé

Trois verbes UDP, **pour le banc**, non consommés par `calaos_server`. Contrat dans
[PROTOCOL-4.0.md](../PROTOCOL-4.0.md).

1. `WAGO_GET_LAYOUT` → `WAGO_LAYOUT <start_addr_in> <start_addr_out> <scan_error> <dali647_in>
   <dali647_out> <feedback_last>`. Les trois derniers valent **`NA`** si `CONFIG_DALI_647 = FALSE` :
   personne n'écrit `daliFeedback` sans la borne, et `0` est son « tout va bien ». C'est la règle ⭐
   de [T-9](../done/T-9.md) appliquée à nous-mêmes — jamais « je ne sais pas » dans le domaine des
   valeurs. Nouveau verbe plutôt qu'une extension de `WAGO_INFO` : personne ne le parse.
2. `WAGO_GET_INFO_MODULE <n>` étendu **en fin** : `<posPAE> <posPAA> <channels> <altFormat>`, et `p1`
   borné à `0..63`. ⚠️ À vérifier dans `calaos_base` que `WAGO_MODULE` n'est pas parsé par nombre de
   champs ; sinon, nouveau verbe `WAGO_GET_MODULE_DESC`.
3. `WAGO_GET_OUTPUT_WORD <w>` → `WAGO_OUTPUT_WORD <w> <valeur>`, via une instance locale
   `READ_OUTPUT_WORD` dans `UDPServer`. C'est l'instrument de l'essai E2 du dossier : une valeur
   figée à 0 malgré nos `write_word` dit « écrasement au rafraîchissement », une valeur qui change
   sans nous dit « quelqu'un d'autre écrit ».

Version annoncée : **inchangée, `4.0`**. C'est la version en cours de construction, pas encore
sortie ; ces verbes en font partie. La version n'est incrémentée qu'après une sortie.

`UDPServer` s'exécute avant `DaliPrg647` dans le cycle : `feedback_last` est celui du cycle
précédent, sans importance pour un diagnostic. Le filtre `udpReplyMisattributedToDaliGet` du serveur
ne jette un verbe `WAGO_*` inconnu que pendant une lecture DALI en vol ; sur banc on n'enchaîne pas
les deux.

## 3. Acceptation

1. Sur R0, `WAGO_GET_LAYOUT` rend `WAGO_LAYOUT 0 0 0 NA NA NA`.
2. Sur R1, il rend `192 192 0 0 0 0`.
3. `WAGO_GET_INFO_MODULE 0` sur R1 rend `647` puis les tailles `192 192`, puis `posPAE = 0`,
   `posPAA = 0`, et les valeurs de `channels` / `altFormat` — qui seront alors **lues pour la
   première fois**.
4. `WAGO_GET_OUTPUT_WORD <start_addr_out / 16>` reflète un `WAGO_SET_OUTPUT 0 1` en dégradé.
5. `WAGO_GET_INFO_MODULE 99` ne lit pas hors tableau.

## 4. ⛔ Le nu

Rien n'a été exécuté. La signature de `READ_OUTPUT_WORD` est **déduite** de celle de
`READ_INPUT_WORD` (`WORD_ADDRESS: WORD` → `VALUE: WORD`, `ERROR: BOOL`, `SYM_XML:736-740`) : ce FB
n'a jamais été instancié dans le projet, sa table de symboles n'existe pas, le compilateur tranchera
au premier build. Que `calaos_server` ignore `WAGO_MODULE` ou le lise par position est **à vérifier
dans `calaos_base`**, pas depuis ici.
